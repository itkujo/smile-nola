# Smile NOLA

Luxury event experience brand — websites, forms, and digital touchpoints.

## Apps

- `apps/intake` — Conference / booth intake form (Next.js, kiosk-mode for iPad)

## Quick start

```sh
cd apps/intake
pnpm install
pnpm dev          # http://localhost:3000
```

See [`apps/intake/BOOTH_SETUP.md`](apps/intake/BOOTH_SETUP.md).
